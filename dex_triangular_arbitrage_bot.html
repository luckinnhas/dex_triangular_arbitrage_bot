Guia Rápido
1

Hospede este arquivo HTML na Web (HTTPS)

A MetaMask Mobile bloqueia arquivos locais (file://). Suba o arquivo gratuitamente na Vercel ou GitHub Pages.

2

Abra o Navegador Interno da MetaMask

No app MetaMask do celular, toque no ícone de Bússola / Globo (Navegador) no menu inferior e cole o link da sua página hospedada na Vercel.

3

Conecte e Selecione a Rede Polygon

Ao abrir o link no navegador da MetaMask, toque em "Conectar MetaMask". A carteira solicitará autorização e injetará o provedor Web3 automaticamente.

# Bot de Triangulagem DEX Polygon 24/7
from web3 import Web3
from decimal import Decimal
import time

w3 = Web3(Web3.HTTPProvider("https://polygon-rpc.com"))
print("Conectado ao Polygon:", w3.is_connected())

CAPITAL = Decimal("1000.00")
META_DIARIA_MAX = Decimal("0.0050") # 0.50%
acumulado = Decimal("0.00")

while True:
    roi = acumulado / CAPITAL
    if roi >= META_DIARIA_MAX:
        print(f"Meta de 0.50% atingida ({roi*100:.3f}%). Pausando...")
        time.sleep(3600)
        continue
    # Escaneamento real de livros de liquidez QuickSwap/Uniswap
    print("Escaneando percursos triangulares USDT...")
    time.sleep(2.5)
